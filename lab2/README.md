# ООП. ЛР2, семейство C, вариант 18

Класс `Matrix` владеет плоским массивом `double*` и реализует возведение квадратной матрицы в неотрицательную целую степень. Номер варианта назначен в журнале группы 203.

## Сборка и тесты

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
& .\build\oop_lab2.exe
```

Проект использует C++20 и Google Test. Для первой конфигурации нужен доступ к GitHub или локальный исходник Google Test через `-DFETCHCONTENT_SOURCE_DIR_GOOGLETEST=...`.

## Как устроен класс

- **Хранение.** В матрице `rows × cols` строка занимает `cols` соседних ячеек. Чтобы попасть в строку `row`, пропускаем `row * cols` элементов. Затем прибавляем `col`.
- **RAII.** Конструктор выделяет `new double[rows * cols]` после проверки размера. Деструктор вызывает `delete[]`. Пустая матрица использует `nullptr`, который можно передать в `delete[]`.
- **Копирование.** Копирующий конструктор выделяет отдельный массив и копирует числа. Поэтому изменение элемента в копии не меняет оригинал.
- **Перемещение.** Перемещающий конструктор передаёт указатель и размеры за постоянное время. Исходный объект становится пустым и его можно повторно присвоить.
- **Присваивание.** В `operator=(Matrix other)` параметр уже скопирован или перемещён к моменту входа. Затем `swap` меняет указатель и размеры. Старый буфер освобождается деструктором параметра. При ошибке выделения во время копирования тело оператора ещё не выполнялось, поэтому исходное состояние сохраняется.
- **Умножение.** Для `A(m × k)` и `B(k × n)` результат имеет размер `m × n`. Элемент результата — сумма `A(row,j) * B(j,col)` по `j`. Запись идёт во временную матрицу, поэтому можно посчитать и `A.mul(A)`. Рабочий буфер заменяется после расчёта.
- **Степень.** `pow(0)` возвращает единичную матрицу. Для положительной степени начинаем с копии `A` и домножаем её на `A` ещё `n - 1` раз. Например, для `[[1,2],[3,4]]` квадрат равен `[[7,10],[15,22]]`.

При неверном индексе `get` и `set` выбрасывают `std::out_of_range`. Неподходящие размеры для `add`, `mul` и `pow` дают `std::invalid_argument`. Если буфер слишком большой, конструктор выбрасывает `std::length_error`. У матрицы с нулевой длиной одной из осей ноль элементов.
